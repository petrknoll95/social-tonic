# social-tonic

Research for an early-stage Czech-based founder exploring non-alcoholic functional drinks for the EU. The repository retains its original name; the research spans focus, productivity, energy, relaxation, social occasions, sleep and selected adjacent categories.

The intended consumer format is a finished, ready-to-drink liquid in a can or bottle. The primary launch concept is CBD-free; CBD is assessed independently as a possible extension. No formula, launch country, category or budget has been selected.

Start with the [research index](research/README.md) and the [US functional RTD landscape, dated 17 October 2026](research/market/01-us-product-landscape/README.md).
